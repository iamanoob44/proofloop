# ProofLoop

AI proposes tests. People review their business meaning. Deterministic execution records the evidence.

ProofLoop is a local prototype for engineers maintaining a fictional creator-commerce checkout quote service. It explores the gap between writing requirements and trusting generated regression tests. The completion boundary is one immutable catalog, one checkout endpoint, structured JSON proposals, revision-based review, and inspectable execution history.

Business rules in SPEC.md are proposed assumptions awaiting the project owner's acceptance. There are no real payments, authentication, tenancy, browser agents, or production commerce integrations.

Implementation and verification notes will be added as each stage runs. This repository excludes confidential source materials.
